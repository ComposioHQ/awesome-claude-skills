# md2video-audio

Automatically convert local Markdown files into MP4 videos containing visuals and free speech, achieving completely zero-cost and third-party API-free automated audio-visual synthesis.

## When to Use This Skill

- Automatically triggers when users request converting Markdown files into videos, producing spoken-word videos, or performing audio-visual synthesis.
- Rapidly transforms technical documentation, blog posts, or knowledge summaries into MP4 videos featuring human voiceover narration and exquisite PPT display visuals.

## What This Skill Does

1. **Environment Dependency Check and Installation**: Automatically detects and installs necessary dependencies such as `edge-tts`, `moviepy`, `markdown`, `marp-cli`, and `ffmpeg`.
2. **Markdown File Preprocessing and Splitting**: Conducts semantic review and typesetting optimization on the input Markdown, generates independent intermediate files, and strictly ensures that the page separators (`---`) in the voiceover script and presentation script match in quantity to guarantee audio-visual synchronization.
3. **One-Click Video Packaging**: Seamlessly synthesizes the presentation script (Marp PPT) and voiceover script (Edge-TTS audio) into high-quality MP4 videos by invoking built-in scripts.
4. **Intelligent Fallback Solutions**: Provides multi-layered fallback strategies to ensure automatic switching to backup scripts when mainstream workflow exceptions occur, securing smooth video production.

## Example

**User**: "Please convert intro.md in the current directory into a video with voiceover."

**Output**:

- Automatically completes environment dependency checks and installation for `edge-tts`, `moviepy`, `marp-cli`, etc.
- Intelligently generates optimized intermediate files: `new-intro-1725181200.md`, `speaking-intro-1725181200.md`, and `show-intro-1725181200.md`.
- Successfully invokes `ai-2md2marp2av.py` and outputs the final rendered high-definition `show-intro-1725181200-1725181300.mp4` talking-head video in the sandbox.

## Tips

- **Maintain Consistent Separators**: The number of `---` separators in the spoken script and presentation slides must correspond strictly one-to-one; this is the key to preventing audio-visual misalignment.
- **Leverage Hierarchical Structure**: Providing high-quality input Markdown with clear `#` and `##` headings significantly improves the layout quality of PPTs automatically generated by Marp.
- **Environment Precheck**: If `ffmpeg` is missing in the sandbox environment, ensure it is automatically or proactively installed via `apt-get install -y ffmpeg`.
