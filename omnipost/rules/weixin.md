## 红线（发布前必查）
- ❌ **诱导分享（外链规范 2.1）**：「分享后可看全集/答案」、利益诱导分享（红包、优惠券、集赞、砍价、助力）、「不转不是中国人」式胁迫文案。
- ❌ **诱导关注（外链规范 2.2 / 运营规范 3.3.2）**：「关注后方可查看答案/领红包/参与活动」。
- ❌ **违规导流（运营规范 3.3.3）**：噱头诱导进公众号下发违规内容；擦边标题引导跳其他图文/第三方网页/小程序；诱导性小程序卡片。
- ❌ **「阅读原文」滥用（3.16.2/3.16.4）**：正文无有效内容、逼用户点「阅读原文」或扫码看落地页且落地页有营销/欺诈风险；「答案在阅读原文」式话术。
- ❌ **过度营销（4.8，12 款）**：保健品夸大、荐股留联系方式、故事+二维码引导加微信、收益承诺、假借专家推荐、**嵌入识别码/口令获取用户关系链（4.8.10）**、夸大收益的课程广告。
- ❌ **广告不标识（4.20）**：内容构成广告必须标明「广告」字样；医疗/药品/保健食品广告须经审查;未经腾讯审核的第三方商业营销违规。
- ⚠️ **外链连带责任（3.25）**：文章里插入的外链落地页违规，公众号一并担责——**插外链前确认落地页干净**（被微信限制过的域名绝对不能放）。

## 可以做什么（与其他平台的关键差异）
公众号**文章内允许插外链**（受外链规范约束），也有「阅读原文」位——这是少数可以合规放链接的中文平台；但链接内容必须干净、不得配合诱导话术。

## 违规后果（官方明示，运营规范第 9 节阶梯处罚）
警告 → 删粉 → 限制/禁止功能 → 短期或**永久封号直至注销**；封禁后注册所用邮箱/身份证/微信号被冻结不能再注册。诱导类典型处罚：文章禁转发、删文、删粉。外链违规：链接被限制打开、域名整域封禁。

## 发布特性提示
- **正式发布走「发表」(freepublish)，不是「群发」**——两者不同：
  - **发表 (freepublish)**：生成一个公开可访问的图文链接，**不推送粉丝、不占群发次数、可重复**。OmniPost 的"正式发布"用它。**仅 API 模式**（已认证服务号 + appId/appSecret + 服务器 IP 白名单）可自动完成。
  - **群发 (masssend)**：推送给所有粉丝，**不可撤回 + 次数有限**（订阅号每天 1 次、服务号每月 4 次，流传共识）。**OmniPost 永不自动群发**，需人工到后台操作。
- **浏览器扫码登录**的账号：微信网页后台把内容公开的动作只有「群发」，没有可脚本化的安全「发表」，所以只能**建草稿**；请求正式发布会回 `MANUAL_PUBLISH`，提示改用 API 模式或人工群发。
- 标题不得夸大误导、关键词堆砌（3.16.1/4.11）。

**建议流程：① 配了认证服务号 API → 直接正式发布(发表)拿公开链接；② 只扫码登录 → 草稿建好后人工到后台确认，需要推送粉丝时再手动群发（谨慎，限次不可逆）。**
