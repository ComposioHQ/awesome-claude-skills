# 院校名单与学历判定

核实候选人学历门槛时的对照表。名单非穷尽：遇到名单外院校，查 QS / US News 排名定级，并在检索记录中注明定级依据。

## 国内 C9（九校联盟）

清华大学、北京大学、复旦大学、上海交通大学、浙江大学、中国科学技术大学、南京大学、哈尔滨工业大学、西安交通大学。

判定提示：

- 毕业年份在校名合并期间的一律算 C9（如哈工大威海、西安交大苏州研究院等按校本部判定，除非岗位另有要求）
- **中科院各所**（计算所、自动化所、软件所、数学院等）与国防科大等同国内顶级，但不在 C9 名单内——默认纳入候选人池，在「学历」列如实标注，是否剔除由用户岗位要求决定
- 其他 985（人大、北航、同济等）默认不满足「C9」硬门槛；若候选人其他条件极强，作为特例向用户说明后再决定

## 海外院校分级（AI / 量化方向加权）

**T0 顶级**：Stanford、MIT、Berkeley、CMU、Harvard、Princeton、Caltech、Oxford、Cambridge、ETH Zurich、EPFL。

**T1 一流**：Columbia、Cornell、Yale、UPenn、Brown、Dartmouth、UCLA、UCSD、UW、UIUC、Michigan、Georgia Tech、UT Austin、NYU（Courant）、Wisconsin-Madison、Maryland、Duke、Chicago、JHU、Purdue、Rice、USC、Toronto、Waterloo、UBC、McGill、NUS、NTU、Imperial College London、UCL、Edinburgh、Tokyo、Kyoto、TUM、ENS Paris、EPITA 以外的法国工程师学校（如 Polytechnique）。

**T2 知名**：QS 前 200 其余院校及各国头部（澳洲 Go8：Melbourne、Sydney、ANU、UNSW 等；荷兰 TU Delft、Amsterdam；瑞典 KTH；以色列 Technion、Weizmann；韩国 SNU、KAIST 等）。

判定原则：

1. **AI 岗位看组不看校**：T2 院校的顶级组（如 KAIST 的 ML 组、Weizmann 的 CS 系）不弱于 T1 普通组；以导师、代表作、引用为准
2. **量化岗位看重数学/CS 强校**：CMU、MIT、Berkeley、Stanford、清华、北大、港科大、Waterloo、ETH 天然加权
3. 专业不限 CS：数学、物理、EE、统计、运筹背景在量化岗都算数
4. 只认**一手来源**：LinkedIn 教育栏、个人主页、论文署名单位、博士论文标题页、GitHub 组织。搜索聚合页与二手报道只作线索，不作核实依据

## 边界情形

- **转学/联培/双学位**：以最终学位授予院校为准；重要经历（如清华本科 + 海外博士）两段都写进「学历」列
- **访问学者/交换**：不算学历，只算经历
- **在职博士/远程硕士**：如实标注，由用户判断是否认可
- 核实失败但其他证据链完整的，标「待核实」并记录证据，不直接剔除

## 知名实验室判定（「大学实验室经历」列用）

「知名」标准，满足其一即可：

1. 导师是该方向知名学者（高被引、顶会最佳论文、院士/会士级）
2. 实验室是该方向公认的产出重镇
3. 实验室成员常年发顶会/顶刊

填写要求：

- 格式「学校 + 实验室/组名（年份区间）」，如「清华大学 THUNLP（2016-2018）」
- 只写五遍交叉验证核实过的；导师页面、实验室成员页、论文署名单位、博士论文致谢是一手来源
- 没有核实到的留空，不编造

常见 AI 实验室参考（非穷尽，遇名单外按上述标准判断）：

- 国内：清华 THUNLP / KEG / 叉院，北大 CFCS / TANGENT，上交 MVIG / 思源，浙大 CAD&CG，中科大 LINKE，哈工大 SCIR，南大 LAMDA，复旦 NLP 组
- 香港/海外：HKU/CUHK/HKUST 各 CS 组，Stanford SAIL / NLP Group，MIT CSAIL，CMU LTI / MLD，Berkeley BAIR，UW NLP / Robotics（Dieter Fox 组），ETH / EPFL 各 ML 组，Oxford / Cambridge ML 组
- 量化方向：高校金融数学、金融工程、统计、运筹系所同样算数，按上述三条标准判断
