# 产品化输出模板 Productize Template

诊断出结论后，用户可要求「产品化输出 Productize」：AI 用本模板把诊断结论转成可直接使用的
产品化材料（文案/结构/定价卡），作为给用户的材料，不修改用户的产品。
After a diagnosis the user may ask for "productize": the AI converts the verdict into usable
product materials (copy / structure / pricing cards). These are materials FOR the user; the AI
never modifies the product itself.

## 1. 30 秒 Pitch（诊断报告的口语版）
公式 Formula：为【人群 + 决策状态】解决【痛点】，通过【方案】，因为【为什么是你】。
For [segment + decision state] who [pain], we do [solution], because [why you].
- 示例 Example：为「已决定出海、正在选工具的一人创业者」解决「工具碎片化、合规踩坑」，
  提供一个建站 + 营销 + 合规一体的工具箱，因为它按出海流程预配置、7 天可上线。
- 检查 Check：30 秒内能说清；删掉任何一句都不成立。

## 2. 一句话价值主张 One-line Value Proposition
模板 Template：
- 对【精确人群 + 决策状态】
- 提供【一句话核心价值】
- 相比【替代方案/什么都不做】，优势是【差异点】
For [exact segment + decision state], we provide [core value in one line]; vs [alternative/doing nothing], the edge is [differentiator].

## 3. 落地页首屏（Hero）结构 Landing Page Above-the-Fold
1. 主标题 Headline：用户结果导向（「7 天上线你的出海网站」），不是功能罗列
2. 副标题 Subhead：一句话解释怎么做 + 为谁
3. CTA：单个主行动（免费试用 / 预约演示），颜色与文案可点击
4. 信任点 Trust markers：3 条（用户数、案例、合规背书、退款保证）
5. 价值证据 Evidence：截图 / 数字 / 前后对比（放首屏下方第二屏）
6. 价格与 FAQ：放在最后，减少决策摩擦

## 4. 三档定价卡 3-Tier Pricing Card
| 档位 Tier | 定价 Price | 包含 Included | 边界 Boundary |
| 免费 Free | 0 | 核心价值试用（限制数量/次数） | 用满即升级 |
| 标准 Standard | 中档（对标竞品 30-60% 价格） | 完整核心价值 | 主要付费档 |
| 专业 Pro | 高档（2-3x 标准） | 多账号/合规审核/优先支持 | 高客单用户 |
- 锚定原则 Anchoring：标准档对标市场价，专业档让标准档显得划算。
- 免费/付费边界必须与「核心价值兑现」挂钩，而不是功能数量。

## 6. 验收清单 Acceptance Checklist
- [ ] 30 秒 pitch 能背给陌生人听并得到追问
- [ ] 一句话价值主张 = 报告第 2 环节（真实需求）的结论
- [ ] 首屏 5 秒内说清「为谁、解决什么、怎么做」
- [ ] 定价卡的三档边界与报告付费转化环节一致
- [ ] 渠道清单里的每个渠道都能说出目标用户真实聚集的证据

## 使用方式 How to Use
- 触发语 Trigger：诊断后说「给我做产品化输出 / productize my pitch」。
- AI 输出 Output：按本模板生成完整材料（含示例文案），标注哪些数字需要用户确认；
  用户确认后自行落地，AI 可复检文案是否与诊断结论一致。
- 与修复模式的关系 Relation to Repair：产品化输出是修复方案里「价值主张 / 获客 / 付费转化」
  环节的可选交付物，不替代完整修改方案。
